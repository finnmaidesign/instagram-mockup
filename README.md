# Daruma Jeans · Instagram profile mockup

Concept mockup of the Daruma Jeans Instagram profile, as a visitor sees it, with the proposed feed.
Not affiliated with Instagram.

**View it:** open the GitHub Pages link in the repo's About section, or download the repo and double-click `index.html`.

- `index.html` – the mockup (desktop and phone layouts; tap a post to open it)
- `my-posts/` – the feed images (colour-graded) and the pinned 3-tile panorama
- `image-prompts.md` – the image-generation prompts and text layout for the feed
- `grade.py` – the colour grade used on every feed image
- `split-panorama.command` – cuts the panorama into the 3 images to post
